# Критерии приёмки MVP

Первый этап считается готовым после прохождения сценариев на Windows 10 и Windows 11 из установленной сборки. Здесь описано ожидаемое поведение, а не отчёт о выполнении тестов.

## Главная и навигация

- Главная страница запускается на русском языке и ясно показывает назначение приложения и состояние локальной библиотеки.
- Навигация доступна к четырём отдельным агентам: документооборот, деловая переписка, Excel-аналитика, презентации PowerPoint.
- Экраны агентов независимы. Локальный предпросмотр не делает сетевых вызовов; сетевой ИИ-действие невозможно без настроенного ключа и отдельного подтверждения конкретного payload.
- Unicode-текст на русском и казахском отображается корректно.

## Библиотека документов

- Разрешена загрузка DOCX, XLSX, PPTX, PDF, JPG/JPEG и PNG; неподдерживаемые, некорректные и превышающие лимит файлы отклоняются с понятным сообщением.
- Загрузка сохраняет оригинальные байты; скачанный файл имеет те же SHA-256 и размер.
- Пользователь может найти документы по имени, фильтровать по типу/дате и сортировать по поддерживаемым колонкам.
- Совпадающие SHA-256 распознаются как дубликаты, не приводят к незаметной перезаписи. UI сообщает, что произойдёт при повторном импорте.
- После отдельного подтверждения повторного импорта создаётся новая запись, связанная с уже сохранёнными байтами; физическая копия остаётся одна.
- Формат проверяется по сигнатуре/структуре содержимого, а не только по расширению или MIME из браузера.
- Поиск без учёта регистра работает для Unicode-имён на русском и казахском; тип и даты фильтруются, список сортируется.
- В текущей библиотеке нет удаления, перемещения или переименования файлов.

## Журнал и настройки

- Успешные и неуспешные ключевые операции видны в локальном журнале с временем и понятным статусом.
- Журнал не содержит содержимое файлов, секреты или токены.
- Настройки можно изменить, закрыть и увидеть сохранённое значение при следующем запуске.

## Локальность и безопасность

- База, документы, настройки, журналы, история и резервные копии находятся в пользовательском каталоге Windows отдельно от установки.
- Backend доступен только на `127.0.0.1`; попытка подключения к IP-адресу машины из сети невозможна.
- Неавторизованный браузерный запрос к API блокируется; произвольный путь не позволяет читать/перезаписывать файл вне хранилища.
- Перезагрузка приложения не теряет библиотеку и настройки.
- В репозитории нет рабочих документов, базы, секретов или резервных копий; фикстуры обезличены.

## Резервное копирование и восстановление

- Пользователь может создать локальную резервную копию, выбрать/узнать её расположение и получить результат операции.
- Архив предупреждает об отсутствии шифрования и содержит базу, настройки, журнал, метаданные и оригиналы библиотеки с SHA-256.
- Восстановление из выбранного пользователем ZIP-файла предваряется отдельным подтверждением; API дополнительно требует подтверждающий флаг.
- Приложение проверяет полный состав, размеры, хеши, целостность и версию SQLite до замены; пути элементов архива не могут выйти за staging-каталог.
- После восстановления библиотека и настройки соответствуют состоянию на момент копии; повреждённый архив не оставляет базу в частично заменённом состоянии.
- Минимальная история задач восстанавливается вместе с SQLite; содержимое предпросмотра в резервную копию не попадает.

## Установка и первый запуск

- Установщик ставит программу на чистую Windows 10/11 без предварительной установки пользователем Python, Node.js или Git.
- Установка/обновление не перезаписывает пользовательскую базу и документы.
- Удаление приложения не удаляет пользовательские данные без отдельного явного выбора.
- Во время установки нет обязательного доступа к внешним API; MVP использует только локальные функции.

## Локальный предпросмотр агентов (этап 9)

- При выборе задачи доступны только типы документов, разрешённые её allow-list.
- В длинной библиотеке документы можно найти по имени на всех страницах результатов и выбрать через пагинацию.
- Для синтетических DOCX, XLSX и PPTX интерфейс показывает локально извлечённый текст; кириллица и казахские буквы отображаются корректно.
- XLSX показывает сохранённые значения, не вычисляет формулы; PPTX показывает слайды в числовом порядке.
- Текстовый PDF может быть выбран и предпросмотрен локально; зашифрованный PDF отклоняется. Сканированный PDF без текстового слоя и изображения не запускают OCR.
- Оригинальный SHA-256 и размер остаются прежними; текст предпросмотра отсутствует в SQLite и журнале.
- Локальный предпросмотр не отправляет данные наружу; экран отличает его от отдельного этапа передачи поставщику.
- После успешного предпросмотра запись появляется в локальной истории; в ней нет имени файла, инструкции, извлечённого текста или результата.

## Подтверждение передачи OpenAI (новый этап, ручная проверка на Windows обязательна)

- Ключ сохраняется в Windows Credential Manager; API и UI не возвращают его значение. Ключ не обнаруживается в SQLite, журнале, резервной копии, исходниках или GitHub Actions.
- Без ключа передача недоступна. Сохранение ключа само по себе не вызывает OpenAI.
- Подготовка карточки запроса не обращается к сети. Карточка показывает поставщика, модель, цель, выбранные файлы и категории, точный JSON body, размер, SHA-256, срок действия и предупреждение о внешней обработке и возможной стоимости.
- Без обязательной галочки и отдельного нажатия кнопки выполнения сетевого вызова нет. Отмена/отказ/истечение и повторное выполнение одного request ID не вызывают повторный запрос.
- Адаптер использует только фиксированный HTTPS host/path, ограничивает размер тела/ответа, не следует редиректам и не повторяет запрос автоматически. CI/unit tests используют mock-транспорт; реальных API-запросов в проверках нет.
- Успешный ответ сохраняется отдельно от оригиналов в `agent_task_results`; история показывает признак наличия ответа. Ответ переживает перезапуск и резервное копирование. Он хранится незашифрованно внутри локальной базы.
- Для документооборота и переписки ответ скачивается в DOCX, для Excel-аналитики — XLSX, для презентаций — PPTX. Файл формируется из сохранённого ответа, оригиналы не меняются; активный контент/макросы не добавляются.
- Текст результата, похожий на формулу Excel, сохраняется как текст, чтобы ячейка не выполнялась при открытии книги.
- До практического использования на Windows проверить Credential Manager и сетевой путь с синтетическим документом, под ключом пользователя и только после проверки точного текста в карточке.
