# Подготовка передачи данных ИИ-агентам

## Текущий объём

Репозиторий содержит доменный формат раскрытия данных и прикладной шлюз одноразового согласия. Он работает только в памяти, не хранит текст в SQLite и не выполняет сетевые запросы. Локальный маршрут предпросмотра извлекает текст DOCX, сохранённые значения XLSX и текст PPTX, чтобы показать выбранные данные пользователю. Он не выдаёт разрешение на отправку и не выполняет сетевых запросов. OpenAI Agents SDK, отправка данных, ключи и настройки поставщика пока не подключены.

## Что должно быть показано перед передачей

Перед отдельным действием пользователя интерфейс должен показать:

- поставщика и целевую модель;
- выбранный агент, задачу и понятную цель обработки;
- точные выбранные файлы или другие источники по их локальным именам;
- категории данных из каждого источника;
- подготовленный текст, который будет отправлен, с возможностью отменить действие.

Сохранённый API-ключ, включённая настройка поставщика или прошлое согласие не заменяют согласие на текущий запрос.

## Локальное извлечение и предпросмотр

Маршрут `/api/v1/agents/{agent_id}/tasks/{task_code}/preview` принимает не более пяти внутренних ID библиотеки и пользовательскую инструкцию. Сервис повторно проверяет задачу, категорию документа, путь и формат. Он читает только текстовые XML-разделы Office ZIP-контейнера через поток `zipfile`, не распаковывает архив на диск, не вычисляет формулы и не запускает макросы или вложения. Разделы ограничены 8 МиБ, контейнер — 10 000 элементов/500 МиБ распакованного размера, один документ и итог — 300 000 символов. XML с DOCTYPE/ENTITY и архивы с повторяющимися именами отклоняются. Результат возвращается только в текущий локальный ответ API с `Cache-Control: no-store`; он не записывается в БД или журнал. PDF и изображения пока отклоняются.

## Техническая граница

`TransferManifest` описывает поставщика, назначение, выбранные источники, категории, предпросмотр и SHA-256 точного исходящего тела. `AgentTransferConsent` выдаёт короткоживущий одноразовый receipt только после явного подтверждения. Перед вызовом адаптера receipt проверяет поставщика, размер и SHA-256 тела; изменённый payload, повторное использование, истечение срока и отмена завершаются отказом.

Каждый агент имеет собственный allow-list типов задач с неизменяемыми кодами, целями и разрешёнными категориями данных. Локальный API может отдать этот каталог интерфейсу через `GET /api/v1/agents/{agent_id}/tasks`. Шлюз согласия сверяет тип задачи, точное описание цели и категории с каталогом; произвольные значения от клиента отклоняются. Этот маршрут только читает локальные описания и не подготавливает payload.

Pending-запросы и receipts хранятся только в памяти процесса. После закрытия приложения согласие недействительно. Сервис ничего не отправляет и ничего не журналирует; в будущем журналировать можно только код события, поставщика, агента, тип задачи, категории и число источников, не содержимое и не ключ.

Локальный экран предпросмотра имеет отдельную минимальную историю подготовки: время, агент, код задачи, состояние предпросмотра и число источников. Имена файлов, инструкции, исходный текст и тело будущего запроса там не хранятся. Эта запись не означает согласие на передачу.

Для агентов должны применяться минимальные allowlist категорий и внутренние ID источников. Нельзя передавать абсолютные пути, произвольные локальные файлы, макросы, активное содержимое или незапрошенные метаданные. Размер одного исходящего тела ограничен 20 МиБ; более крупный контент потребует отдельного подтверждаемого разбиения.

## До подключения OpenAI

Требуется решить, какие модели и задачи разрешены, как извлекать и показывать фрагменты Office/PDF, какие ограничения хранения и региона выбрать, как объяснить обработку поставщиком, и какие данные вообще допустимо передавать. Ключи должны храниться через Windows Credential Manager либо эквивалентное защищённое системное хранилище. Нельзя помещать ключи в SQLite, `.env`, GitHub Actions, логи или резервные копии.

Подключение SDK следует добавить за отдельным provider adapter после утверждения этих решений. Отказ, отмена или ошибка до передачи не должны вызывать внешний запрос. Результаты ИИ сохраняются отдельно от неизменяемых оригиналов и помечаются как сгенерированные.
