# План реализации Office AI

Работы идут последовательно небольшими этапами. Перед началом каждого следующего этапа требуется подтверждение пользователя.

1. **Проектирование** (завершён): назначение, архитектура, модель данных, безопасность, критерии MVP, Windows-сборка и правила Codex.
2. **Каркас приложения** (завершён): минимальная структура React/TypeScript, FastAPI, pywebview, запуск в режиме разработки и разделение модулей. Без ИИ и без доступа к внешним сервисам.
3. **Локальное хранилище и настройки** (завершён): каталог данных пользователя, миграции SQLite, настройки и журнал операций.
4. **Библиотека документов** (завершён): загрузка, проверка типов и размеров, SHA-256, обнаружение дубликатов, поиск, фильтрация, сортировка, скачивание и безопасные пути.
5. **Резервирование и восстановление** (завершён): локальная резервная копия и проверяемое восстановление с подтверждением пользователя.
6. **Интерфейс MVP и экраны агентов** (завершён): главная, навигация, библиотека, настройки и четыре подготовленных самостоятельных экрана агентов без ИИ-вызовов.
7. **Проверки и приёмка MVP** (автоматическая часть завершена; Windows-приёмка ожидает сборки): автоматизированные проверки и сценарии безопасности согласно [`docs/acceptance.md`](docs/acceptance.md). Ручная приёмка установленного приложения на Windows 10/11 остаётся незавершённой.
8. **Windows-сборка** (автоматическая проверка завершена): GitHub Actions на Windows Server 2022 успешно собрал frontend и PyInstaller onedir-пакет, создал Inno Setup установщик, выполнил тихую установку/проверку/удаление и сохранил временный artifact. Ручная проверка GUI на Windows 10/11, включая WebView2 Runtime, остаётся незавершённой согласно [`docs/windows-build.md`](docs/windows-build.md).
9. **Агенты и внешние модели** (начат фундамент согласия): описаны требования и добавлен одноразовый локальный шлюз для подтверждения конкретного payload. Он не подключает сеть, OpenAI SDK, ключи или базу. До provider adapter требуется утвердить модели/задачи, способ извлечения данных и условия передачи.

Этапы 5 и 6 завершены. Автоматические проверки этапа 7 выполнены. Этап 8 автоматически проверен в Windows CI (run 14, успех); ручная проверка GUI на Windows 10/11 ещё не выполнена. Этап 9 начат с локальной основы согласия; внешняя передача пока не реализована. Полная приёмка MVP не завершена.
