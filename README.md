# Office AI

Office AI — настольное приложение для Windows 10/11, которое объединяет локальную библиотеку документов и четыре специализированных помощника: по документообороту, деловой переписке, Excel-аналитике и созданию презентаций PowerPoint.

## Назначение и особенности

- Приложение рассчитано на одного пользователя и работает на его компьютере.
- Интерфейс программы — на русском языке; документы и имена файлов могут быть на русском и казахском.
- Библиотека поддерживает DOCX, XLSX, PPTX, PDF, JPG и PNG. Загрузка сохраняет оригинал без редактирования; скачивание возвращает сохранённый оригинал.
- Поиск, фильтрация, сортировка, обнаружение совпадающих файлов по SHA-256 и журнал операций работают локально.
- Данные, настройки, история задач и резервные копии хранятся в пользовательском профиле Windows, отдельно от каталога программы.
- На первом этапе экраны агентов являются подготовленными интерфейсами. Вызовов ИИ нет.
- В будущем обращение к OpenAI API возможно только после явного согласия пользователя на передачу выбранных данных для конкретной задачи.
- GitHub предназначен для исходного кода, документации, тестов и обезличенных примеров. Реальные документы, база данных, ключи и резервные копии туда не помещаются.

## Планируемый стек

- React и TypeScript — интерфейс.
- Python и FastAPI — локальный backend и прикладные сервисы.
- SQLite — метаданные, настройки, журнал операций и история задач.
- OpenAI Agents SDK — возможная интеграция на более позднем этапе, за отдельной границей согласия.
- pywebview — лёгкая Windows-оболочка для веб-интерфейса; Python поставляется внутри приложения.
- PyInstaller и Inno Setup — упаковка приложения и создание установщика из GitHub Actions на Windows runner.

Подробные решения, ограничения и последовательность работ описаны в [`docs/architecture.md`](docs/architecture.md), [`docs/security.md`](docs/security.md), [`docs/windows-build.md`](docs/windows-build.md) и [`PLANS.md`](PLANS.md).
