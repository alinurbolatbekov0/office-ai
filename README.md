# Office AI

Office AI — настольное приложение для Windows 10/11, которое объединяет локальную библиотеку документов и четыре специализированных помощника: по документообороту, деловой переписке, Excel-аналитике и созданию презентаций PowerPoint.

## Назначение и особенности

- Приложение рассчитано на одного пользователя и работает на его компьютере.
- Интерфейс программы — на русском языке; документы и имена файлов могут быть на русском и казахском.
- Локальная библиотека поддерживает загрузку и скачивание DOCX, XLSX, PPTX, PDF, JPG/JPEG и PNG. Загрузка проверяет содержимое, сохраняет исходные байты и ограничена 100 МиБ на файл.
- Поиск по именам с русским и казахским текстом, фильтры по типу и дате, сортировка и обнаружение дублей SHA-256 работают локально.
- Библиотека, настройки, журнал операций и резервные копии хранятся в профиле Windows, отдельно от каталога программы.
- Резервная копия содержит снимок SQLite и оригиналы библиотеки. Она хранится без шифрования в локальном каталоге `backups`; приложение также предлагает скачать архив.
- Главная, библиотека, настройки и четыре отдельных экрана агентов подготовлены. Для агента можно выбрать задачу и локальные DOCX/XLSX/PPTX, затем посмотреть извлечённый текст до любых будущих действий. ИИ-вызовов и передачи данных нет.
- В будущем обращение к OpenAI API возможно только после явного согласия пользователя на передачу выбранных данных для конкретной задачи.
- GitHub предназначен для исходного кода, документации, тестов и обезличенных примеров. Реальные документы, база данных, ключи и резервные копии туда не помещаются.

## Планируемый стек

- React и TypeScript — интерфейс.
- Python и FastAPI — локальный backend и прикладные сервисы.
- SQLite — метаданные, настройки, журнал операций и история задач.
- OpenAI Agents SDK — возможная интеграция на более позднем этапе, за отдельной границей согласия.
- pywebview — лёгкая Windows-оболочка для веб-интерфейса; Python поставляется внутри приложения.
- PyInstaller и Inno Setup — упаковка приложения и создание установщика из GitHub Actions на Windows runner.

Подробные решения, ограничения и последовательность работ описаны в [`docs/architecture.md`](docs/architecture.md), [`docs/security.md`](docs/security.md), [`docs/windows-build.md`](docs/windows-build.md) и [`PLANS.md`](PLANS.md).

## Состояние проекта

Каркас приложения, локальная библиотека, настройки, журнал операций, резервирование, восстановление и интерфейс MVP реализованы. SQLite, оригиналы и резервные копии хранятся под `%LOCALAPPDATA%\OfficeAI` на Windows. Полная приёмка MVP, история задач и ИИ-вызовы пока не реализованы.

## Запуск каркаса для разработки

Нужны Python 3.12+ и Node.js 20.19+ на машине разработчика. В PowerShell из корня репозитория:

```powershell
cd frontend
npm ci
cd ..
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e backend
python -m office_ai.desktop --dev
```

Команда запускается из корня проекта. Она стартует Vite только на `127.0.0.1`, запускает FastAPI на свободном loopback-порту и открывает интерфейс в pywebview. Закройте окно приложения для остановки обоих серверов. Не запускайте команду с документами или секретами в каталоге репозитория.

Для отдельной проверки API-схемы без окна можно запустить `python -m unittest discover -s backend\tests` из корня после установки backend-зависимостей.
